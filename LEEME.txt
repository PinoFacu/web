1. CREAR LA CLAVE DE GITHUB (una sola vez)
-------------------------------------------
GitHub › foto de perfil › Settings › Developer settings › Personal access tokens
› Fine-grained tokens › Generate new token.
  - Token name: admin remates pinofacu
  - Expiration: la más larga que permita (anotá la fecha de vencimiento)
  - Resource owner: PinoFacu
  - Repository access: Only select repositories › PinoFacu/web
  - Permissions › Repository permissions › Contents: Read and write
    (no hace falta ningún otro permiso)
Copiar el token (empieza con github_pat_). GitHub lo muestra una sola vez.


2. CONFIGURAR EL ADMIN (una sola vez)
-------------------------------------
Entrar a https://pinofacu.com/admin-remates.html (o a la dirección github.io
mientras el dominio no esté listo). Como es la primera vez, pide:
  - la clave de GitHub (el token del paso 1)
  - la contraseña del admin (dos veces)
Al guardar, la clave queda cifrada con la contraseña en remates/admin-key.json.
Desde ahí, en cualquier dispositivo se entra SOLO con la contraseña.

Si vence el token o querés cambiar la contraseña: en la pantalla de ingreso,
"¿Cambiaste la contraseña o venció la clave de GitHub?" › CONFIGURAR ACCESO.


3. USAR EL ADMIN
----------------
- + NUEVO REMATE: nombre, descripción, precio base, estado y hasta 5 fotos.
- Estados: Publicado (recibe ofertas) · Cerrado (se ve, sin ofertas) · Oculto.
- En cada remate: EDITAR, OCULTAR/MOSTRAR, ELIMINAR (borra también sus fotos)
  y ↑ para cambiar el orden en la web.
- Cada cambio es un commit en GitHub. La web se actualiza en 1 o 2 minutos.
- "Recordar en este dispositivo" evita pedir la contraseña de nuevo. No lo
  marques en computadoras compartidas.
- La página del admin no se enlaza desde la web y les pide a los buscadores
  que no la indexen.


4. DOMINIO pinofacu.com
-----------------------
a) Subir el archivo CNAME (ya incluido) a la raíz del repo.
b) GitHub › PinoFacu/web › Settings › Pages › Custom domain: pinofacu.com › Save.
c) En el panel DNS de donde compraste el dominio, cargar:
     Tipo A     Host @     185.199.108.153
     Tipo A     Host @     185.199.109.153
     Tipo A     Host @     185.199.110.153
     Tipo A     Host @     185.199.111.153
     Tipo CNAME Host www   pinofacu.github.io
   (Opcional, IPv6: AAAA @ 2606:50c0:8000::153, 2606:50c0:8001::153,
    2606:50c0:8002::153, 2606:50c0:8003::153)
   Borrar cualquier otro registro A o CNAME de @ y www que venga por defecto
   (por ejemplo, el de "página en construcción" del proveedor).
d) Esperar a que GitHub marque "DNS check successful" (de minutos a 24 h) y
   tildar "Enforce HTTPS".
e) Recomendado: GitHub › Settings (de la cuenta) › Pages › Add a domain,
   para verificar pinofacu.com y que nadie más pueda usarlo.


LÍMITES
-------
La oferta se valida en el navegador antes de abrir WhatsApp. No hay registro
de ofertas, cierre automático, adjudicación ni pagos online: Pino Facu recibe
y gestiona las propuestas por WhatsApp.


PRECIOS DE REVENTA (desde el admin)
-----------------------------------
- Los productos y precios de reventa están en reventa/productos.json.
- En admin-remates.html › pestaña "Precios de reventa": cambiar el precio por
  unidad y tocar GUARDAR PRECIOS. Destildar "Visible" saca el producto de la
  página de reventa sin borrarlo.
- Igual que los remates: cada guardado es un commit y la web se actualiza en
  1 o 2 minutos.
- Si reventa/productos.json no carga, reventa.html usa la lista de respaldo que
  tiene adentro (con los precios originales).
